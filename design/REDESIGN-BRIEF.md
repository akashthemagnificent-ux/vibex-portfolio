# Vibex Redesign Brief — Cobalt Proof Sheet

## Intent

The foundation must feel like the first page of an artist-engineer’s private proof book: precise, lit, tactile, and quietly confrontational. It replaces the previous conventional editorial page with one recognisable object and a controlled sequence of surfaces.

## Page Structure

| Moment | Purpose | Layout and interaction |
| --- | --- | --- |
| Entry | Establish a proprietary identity | An asymmetric hero. The cobalt proof sheet lives on the right; a concise personal statement sits at lower left. The object is the visual protagonist. |
| Proof | Make the visual system legible | The hero object continues across the section boundary, while a two-column statement explains the page as an evolving personal record. |
| Motion | Demonstrate craft without template cards | Three unequal editorial specimens—type, motion, system—appear as a continuous proof strip rather than a symmetrical feature grid. |
| Signal | End with an invitation for the next instruction | A quiet full-bleed cobalt panel, not a generic footer or card. |

## Interaction Principles

The hero object responds to pointer position only on fine pointers. Links get a short positional shift and a visible focus treatment. The navigation uses an active marker that moves with the reader’s position. No autoplay media, sound, particles, marquee, or ambient decoration is permitted.

## Asset Requirement

Generate one original high-resolution visual for the hero proof sheet: a cobalt lacquered folded identity tile with a cut-out four-point Vibex star, photographed on cool mineral paper under hard studio daylight. It must be used as the primary hero visual, not repeated elsewhere.
